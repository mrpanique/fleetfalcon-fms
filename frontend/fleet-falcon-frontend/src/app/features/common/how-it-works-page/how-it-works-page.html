How It Works

FleetFalcon helps employees request vehicles and helps admins keep the fleet available, compliant, and transparent.

Booking Process

  1. 1. Find a vehicle

    Use filters on the Vehicles page to narrow by type, fuel, price range, seats, and availability.

  2. 2. Review vehicle details

    Open Details to check specifications, pricing, and notes before creating a booking request.

  3. 3. Submit booking request

    Choose a start and end date, verify estimated cost, then submit your request.

  4. 4. Admin review

    Admins review pending requests and approve or reject them based on fleet availability and policy.

Booking Lifecycle

PENDING

Request was submitted and is waiting for admin decision.

APPROVED

Booking is accepted and scheduled for pickup/start date.

ACTIVE

Trip is in progress. Start mileage has been recorded.

COMPLETED

Trip is closed with end mileage, distance, and final cost.

REJECTED

Request was declined by admin. Employee can submit a new one.

CANCELLED

Booking was cancelled before check-out.

Who Does What

Employee

  • Search and request vehicles for planned trips.
  • Track booking statuses in My Bookings.
  • Return vehicles on time and provide trip closure data if required.

Admin

  • Review all requests and manage approvals.
  • Monitor fleet status, service dates, and technical validity.
  • Maintain accurate vehicle and booking records.
